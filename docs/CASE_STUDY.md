# NovaBank case study

NovaBank is an academic React and Python banking simulator deployed using API Gateway, Lambda, DynamoDB, IAM, CloudWatch and CloudFormation. S3 stores the deployment archive. API Gateway and Lambda serve both the interface and API.

The verified cloud demonstration on 24 October 2026 processed INR 1,000 from Aarav to Meera. Balances became INR 24,000 and INR 26,000, with matching reference b929ece490. The report contains the captured application and AWS evidence. The repository URL will be added after publishing.
